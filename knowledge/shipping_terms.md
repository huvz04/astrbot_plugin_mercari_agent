# Mercari 运费、配送与包装词

## 运费承担

- **送料込み / 出品者負担**：商品价格包含日本国内运费，由卖家承担。
- **着払い / 購入者負担**：日本国内运费由买家收货时另付，商品标价不包含该费用。

## 配送方式

- **匿名配送**：通过支持匿名的配送方式隐藏交易双方地址。
- **追跡あり**：有物流追踪编号；不等于包含破损或丢失赔偿。
- **普通郵便**：普通邮件，通常应额外确认是否可以追踪和赔偿。
- **定形郵便 / 定形外郵便**：日本邮政普通信件或非标准尺寸邮件，常见于小件谷子。
- **ゆうゆうメルカリ便**：Mercari 与日本邮政合作的配送方式。
- **らくらくメルカリ便**：Mercari 与 Yamato 运输合作的配送方式。
- **発送方法未定 / 未定**：卖家尚未确定配送方式，追踪、匿名和赔偿能力不明确。

## 包装描述

- **簡易包装**：简易包装；纸片、徽章、亚克力等易损商品需要关注具体保护方式。
- **水濡れ防止**：使用塑料袋等进行防水保护。
- **厚紙補強 / 両面補強**：用厚纸板单面或双面加固纸类商品。
- **プチプチ**：气泡膜，常用于徽章、亚克力和模型缓冲。
- **同梱**：合并包装或合并发货；是否能合并通常需要卖家或代购方确认。
