# Mercari 动漫周边别名

这些词用于补充关键词检索，不代表商品真伪、完整性或实际品相。

## 徽章、亚克力与橡胶制品

- **缶バッジ / 缶バ / can badge**：马口铁徽章、圆形徽章；中文谷圈常称“吧唧”。
- **アクリルスタンド / アクスタ**：亚克力立牌。
- **アクリルキーホルダー / アクキー**：亚克力钥匙扣、亚克力挂件。
- **ラバーストラップ / ラバスト**：橡胶挂件、软胶挂件。

## 毛绒与模型

- **ぬいぐるみ / ぬい**：毛绒玩偶；中文谷圈有时写作“努努”。
- **マスコット**：小型毛绒、公仔或吉祥物挂件，需结合图片确认尺寸和材质。
- **フィギュア**：手办、模型；`プライズ` 常指景品手办。
- **ねんどろいど**：黏土人系列商品，购买中古品时应核对脸、手和底座等配件。

## 纸类周边

- **紙類**：纸片类周边的统称，不是单一品类。
- **色紙**：色纸、签绘板形态的纸质周边。
- **ブロマイド**：写真卡、照片卡。
- **ポストカード / ポスカ**：明信片；`ポスカ` 是常见简称。
- **クリアファイル**：透明文件夹。
- **カード / トレカ**：卡片、集换式卡牌；应结合系列名区分普通卡和稀有卡。

## 销售形态

- **特典 / 購入特典 / 店舗特典**：购买赠品、店铺特典，通常不是常规零售单品。
- **限定 / 期間限定 / 会場限定**：限定、期间限定或会场限定；只是销售范围描述，不自动证明稀有或正品。
- **まとめ売り / セット**：多件打包、整组出售；应核对图片和说明中的实际件数。
- **コンプリート / コンプ**：全套、集齐；仍需核对是否写有缺件、重复或仅图中物品。
