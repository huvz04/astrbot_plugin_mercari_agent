# Mercari 交易话术

这些多为卖家写在标题、简介或个人资料中的交易偏好。它们可以帮助 Agent 解释
购买条件，但不能替代平台页面上的实际按钮和订单状态。

- **即購入 / 即購入可 / 即購入OK**：可以直接购买，通常不要求先留言确认。
- **コメント不要**：无需购买前留言。
- **購入前コメント / コメント必須**：卖家希望买家先留言；可能需要代购方人工确认。
- **値下げ不可**：不接受降价。
- **お値下げ / 値下げ交渉**：议价、请求降价；出现该词不表示卖家一定接受。
- **バラ売り不可**：不拆售，只按页面所列整组出售。
- **バラ売り可**：可以讨论拆售；具体对象和单价通常需要另行确认。
- **まとめ売り**：打包出售，需核对总件数、重复款和缺件说明。
- **専用 / ○○様専用**：卖家为特定买家制作的“专用”页面。这是用户间约定，
  不是 Mercari 官方的锁定或预留功能。
- **取り置き**：请求预留商品。这是用户间约定，不等于平台保证库存。
- **早い者勝ち**：先到先得，通常表示卖家不承诺为留言者保留。
- **プロフ必読 / プロフィール必読**：卖家要求先阅读个人资料，其中可能有包装、
  发货或议价条件。
- **購入意思のないいいね不要**：卖家不希望无购买意向的收藏或点赞，不是商品风险。
