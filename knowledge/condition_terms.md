# Mercari 品相与完整性词

品相词是卖家描述，不等于验货或平台担保。中古商品还应结合图片、说明、卖家评价
和保管方式判断。

## 平台常见状态

- **新品・未使用**：卖家选择的“全新、未使用”状态；仍可能存在保管痕迹或初期瑕疵。
- **未使用に近い**：接近未使用，但可能已开封、试用或短期展示。
- **目立った傷や汚れなし**：无明显伤污，不代表完全无细小划痕。
- **やや傷や汚れあり**：有轻微伤污，应重点查看照片和描述。
- **傷や汚れあり**：有明确伤污，购买前应确认位置和程度。
- **全体的に状態が悪い**：整体状态较差，属于高风险品相。

## 卖家常用描述

- **未開封**：包装未拆；不保证内部没有初期瑕疵、老化或缺装。
- **開封済み**：已经拆封。
- **中身確認 / 絵柄確認のみ**：为确认内容或款式而拆开外包装，通常未正式使用。
- **初期傷 / 初期スレ**：生产、装袋或运输阶段形成的初始划痕、擦痕。
- **スレ / 傷 / 汚れ**：擦痕、划伤、污渍；应结合材质和照片判断影响。
- **日焼け / 色あせ**：日晒、褪色，纸类和展示品尤其需要注意。
- **折れ / 凹み**：折痕、凹陷；常见于纸片、徽章和外盒。
- **欠品**：缺少部件、附件、外盒或特典。
- **ジャンク**：故障品、残次品或不保证功能的现状出售商品。
- **現状品 / 動作未確認**：按现状出售或未确认功能，功能性风险较高。
- **経年劣化**：随时间产生的老化、泛黄、黏性变化或材料脆化。
- **自宅保管 / 素人保管**：个人家庭保管，不代表专业仓储或专业品相判断。
- **美品**：卖家的主观“品相较好”评价，仍应以图片和具体瑕疵说明为准。
